## infer-sub quantitative definitions
This directory includes a CSV file containing definitions for each quantitative output file from `infer-subc` `Part 2`. The information in each CSV summarizes the types of metrics derived from each analysis type.

⚠️ **Causion:** Definitions were generated using GitHub Copilot based on the underlying computation included in infer-subc and other packages. The outputs were spot checked for basic accuracy, but a comprehensive review of the definitions has not yet been performed. Use with causion.
